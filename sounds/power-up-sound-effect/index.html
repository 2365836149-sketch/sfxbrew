About these power-up sounds, uses and license

Either a quick rising arpeggio or a filtered sweep that swells upward. Both say "you just got stronger" in under a second. Every press of New in the editor brews a different power-up; these 12 are a fixed selection so the links stay the same.

Good for

  • Collecting a power-up
  • Upgrades and buffs
  • Combo or streak milestones
  • Filling a gauge

Tweaking tip

Each generation picks one of the two styles at random; generate a few to compare. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew powerUp --count 5 --out assets/sfx/power-up.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "power-up sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub

Every sound on this site is made in your browser, from synthesis or a few CC0 recordings, and free for commercial use, no attribution required.
