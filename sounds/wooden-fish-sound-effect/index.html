About these wooden fish sounds, uses and license

The hollow knock of a muyu, the wooden fish struck by monks while chanting, also known as a temple block. Short and woody, with one to three hits per variation. Clicker games have made the "tok" of a wooden fish famous on its own. Every press of New in the editor brews a different wooden fish; these 12 are a fixed selection so the links stay the same.

Good for

  • Clicker and idle game taps
  • Temples, monasteries and chanting
  • Clock ticks and countdowns
  • UI taps with an Eastern feel

Tweaking tip

Single-hit variants are best for repeated taps; double hits work as a "next" or "confirm" sound. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew woodfish --count 5 --out assets/sfx/wooden-fish.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "wooden fish sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
