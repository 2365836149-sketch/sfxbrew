About these rain sounds, uses and license

About four seconds of rain: a soft wash of falling water, dozens of drops hitting different surfaces and a low watery bed. Each variation is light, medium or heavy rain, and it fades in and out so it can loop or be crossfaded. Every press of New in the editor brews a different rain; these 12 are a fixed selection so the links stay the same.

Good for

  • Weather systems and rainy levels
  • Background ambience for villages and forests
  • Sad or calm story scenes
  • Layering under thunder for a storm

Tweaking tip

For a longer bed, loop two variations with a crossfade. Add the thunder preset on top for a storm. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew rain --count 5 --out assets/sfx/rain.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "rain sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
