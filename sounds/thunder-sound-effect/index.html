Every press of New in the editor brews a different thunder; these 12 are a fixed selection so the links stay the same.

Good for

  • Lightning spells and strikes
  • Heavenly tribulation in cultivation games
  • Storm ambience accents
  • Dramatic reveals

Tweaking tip

Delay the rumble layer by a fraction of a second to make the storm feel further away. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew thunder --count 5 --out assets/sfx/thunder.wav

Or let Claude Code, Cursor or any MCP client add them to your project: claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp, then ask for "thunder sounds".
