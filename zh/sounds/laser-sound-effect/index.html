适用场景

  • 激光枪、能量枪
  • 发射子弹、飞行物
  • 科幻风格的界面点缀
  • 射击游戏里的敌人攻击

调音小技巧

音高滑动时长短一些，枪声更干脆；长一些，像一发慢速的等离子弹。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew laser --count 5 --out assets/sfx/laser.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个激光音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
