关于翻页音效：适用场景、技巧和授权

真实的翻书录音，从薄薄的一页纸到旧书厚重的书页。每个变体就是翻一页。 在编辑器里每按一次"重新生成"都会得到一个不同的翻页；这里的 12 个是固定的，方便分享链接。

适用场景

  • 日志、任务记录、图鉴
  • 秘籍、功法、说明书
  • 菜单分页、背包翻页
  • 故事书和新手教程

调音小技巧

凡是在页面之间切换的界面都可以用，比"嘀"一声更有质感。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew pageTurn --count 5 --out assets/sfx/page-turn.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个翻页音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub

本站所有声音都在你的浏览器里实时生成（合成或少量 CC0 录音素材），可免费商用，不需要署名。
