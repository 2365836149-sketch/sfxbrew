关于聚气音效：适用场景、技巧和授权

一个慢慢涨起、带着波动的上升音，最后落在一声钟上，像能量在释放前不断聚集。在修仙游戏里是灵气汇入丹田，在动作游戏里就是蓄力攻击。 在编辑器里每按一次"重新生成"都会得到一个不同的聚气；这里的 12 个是固定的，方便分享链接。

适用场景

  • 蓄力攻击、起手
  • 运功、打坐的周期提示
  • 能量条充满
  • 变身之前

调音小技巧

把第一层的起音拉长，蓄力就更久。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew qiGather --count 5 --out assets/sfx/magic-charge.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个聚气音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
