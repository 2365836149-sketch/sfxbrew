关于通知音效：适用场景、技巧和授权

两声柔和、像马林巴一样的"叮咚"，第二个音往上走一点。是那种告诉玩家"有事发生了"、又不会吓人一跳的提示音。音高都在五声音阶上。 在编辑器里每按一次"重新生成"都会得到一个不同的通知；这里的 12 个是固定的，方便分享链接。

适用场景

  • 消息、弹窗、横幅提示
  • 任务更新、背包里有新东西
  • 好友上线、收到邮件
  • 计时结束

调音小技巧

重要的提醒可以把音高调高、两个音之间的间隔缩短。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew notify --count 5 --out assets/sfx/notification.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个通知音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
