About these explosion sounds, uses and license

Violent blasts: a sharp shockwave, a sub-bass punch, a saturated body that stays at full force before it fades, a mid-range roar, debris raining down at random and a wobbling aftershock. Some variations are a chain of two or three explosions. Every press of New in the editor brews a different explosion; these 12 are a fixed selection so the links stay the same.

Good for

  • Bombs, grenades and barrels
  • Destroying enemies or buildings
  • Big spell impacts
  • Cinematic hits in trailers

Tweaking tip

These are loud on purpose; turn them down a little if your game has many at once. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew explosion --count 5 --out assets/sfx/explosion.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "explosion sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
