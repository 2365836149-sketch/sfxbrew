免费古琴音效

古琴单音，用物理建模的琴弦合成，不是普通的电子音色。每个变体随机一种弹法：散音（空弦，低沉、有木头的共鸣）、按音带走手音（弹完手指在弦上一滑，音高跟着变），或者泛音（轻点弦，空灵得像钟）。所有音都在五声音阶上。

适用场景

  • 东方题材游戏里安静的界面点击
  • 对话逐字出现的提示音
  • 打坐、修炼、炼器的反馈
  • 场景切换之间的短乐句

调音小技巧

打包下载一组，连续操作时依次播放：同一个音阶，连点就成了一小段旋律。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew guqin --count 5 --out assets/sfx/guqin.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个古琴音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
