About these pipa sounds, uses and license

The pipa is a pear-shaped Chinese lute with a bright, percussive attack. These variations come in three playing styles: a single plucked note, the rapid tremolo (lunzhi) the instrument is famous for, and a fast strummed chord. Brighter and more urgent than the guqin. Every press of New in the editor brews a different pipa; these 12 are a fixed selection so the links stay the same.

Good for

  • Tense or action-heavy Eastern scenes
  • Ambush, chase and duel stingers
  • UI accents that need more energy than a guqin
  • Turn start in a card or strategy game

Tweaking tip

The tremolo variants make great "danger is coming" cues; layer one over a war drum. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew pipa --count 5 --out assets/sfx/pipa.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "pipa sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp
