调音小技巧

轰鸣层缩短就是小爆竹，拉长就是远处的炮火。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew explosion --count 5 --out assets/sfx/explosion.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个爆炸音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
