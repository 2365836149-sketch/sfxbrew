调音小技巧

颤音慢一点更哀伤，快一点更激动。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew erhu --count 5 --out assets/sfx/erhu.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个二胡音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
