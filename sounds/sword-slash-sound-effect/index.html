Free Sword Slash Sound Effects

Sharp, airy blade swings with a thin metallic ring at the end. They sit somewhere between a classic sword swoosh and the "sword qi" projectiles of wuxia and xianxia games, so they work for both a katana swing and a glowing crescent of energy flying across the screen.

Every press of New in the editor brews a different sword slash; these 12 are a fixed selection so the links stay the same.

Good for

  • Melee attacks and combo hits
  • Sword qi, wind blades and energy slashes
  • Parry or blade-draw moments
  • Skill icons that cut across the UI

Tweaking tip

For a heavier weapon, lower the noise layer's cutoff and shorten the ring. For a magical slash, raise the reverb. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew swordQi --count 5 --out assets/sfx/sword-slash.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "sword slash sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
