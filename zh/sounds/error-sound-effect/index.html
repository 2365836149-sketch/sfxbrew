关于错误音效：适用场景、技巧和授权

两声低沉、发闷的音，由几个微微走调的声音叠成。足够明显，又不会让经常听到的玩家烦躁。 在编辑器里每按一次"重新生成"都会得到一个不同的错误；这里的 12 个是固定的，方便分享链接。

适用场景

  • 无效操作、被阻止的输入
  • 金币、灵力、体力不足
  • 答错
  • 门或道具被锁住

调音小技巧

第二声往下走更像"错了"；不变调更像"不允许"。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew error --count 5 --out assets/sfx/error.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个错误音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
