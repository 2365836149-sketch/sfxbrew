About these chest open sounds, uses and license

Real recordings of a wooden chest and an old trunk creaking open. Some variations finish with a little sparkle of chimes, the classic "you found treasure" moment. Every press of New in the editor brews a different chest open; these 12 are a fixed selection so the links stay the same.

Good for

  • Treasure chests and loot
  • Crates, cabinets and doors
  • Reward screens
  • Secret rooms being revealed

Tweaking tip

Use the plain creak for ordinary containers and keep the sparkle variations for rare loot. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew chestOpen --count 5 --out assets/sfx/chest-open.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "chest open sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
