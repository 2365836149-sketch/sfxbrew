About these level up sounds, uses and license

A bright arpeggio that lands on a soft chord and a bell. Celebratory without being a full fanfare, so it works even when players level up often. Every press of New in the editor brews a different level up; these 12 are a fixed selection so the links stay the same.

Good for

  • Character level up
  • Achievements and trophies
  • Rewards and chests
  • Completing a stage

Tweaking tip

For the rare, big moments, use Breakthrough instead. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew levelUp --count 5 --out assets/sfx/level-up.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "level up sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub

Every sound on this site is made in your browser, from synthesis or a few CC0 recordings, and free for commercial use, no attribution required.
