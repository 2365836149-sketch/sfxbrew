关于突破音效：适用场景、技巧和授权

一声低沉的钟、一阵闷响，再加一串往上走的拨弦琶音：踏入新境界的声音。比普通的升级隆重得多，留给少见而重要的时刻。 在编辑器里每按一次"重新生成"都会得到一个不同的突破；这里的 12 个是固定的，方便分享链接。

适用场景

  • 修仙、放置游戏的境界突破
  • 转生、重置
  • 主线剧情的重大节点
  • 解锁新地图

调音小技巧

平时的进度用更短的"升级"音效，大境界才用这个。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew breakthrough --count 5 --out assets/sfx/cultivation-breakthrough.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个突破音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
