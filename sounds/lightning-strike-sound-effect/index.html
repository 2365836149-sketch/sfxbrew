About these lightning sounds, uses and license

Real recordings of lightning striking close by: the deafening crack and the roar that follows, each variation pitched slightly up or down so it sounds bigger, smaller or further away. Fast and violent where Thunder is slow and brooding. Every press of New in the editor brews a different lightning; these 12 are a fixed selection so the links stay the same.

Good for

  • Lightning spells and skills
  • The moment a heavenly tribulation strikes
  • Electric traps and storms
  • Dramatic cuts and reveals

Tweaking tip

Layer it over a Thunder rumble for the full storm, or over an Explosion for a lightning-powered blast. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew lightning --count 5 --out assets/sfx/lightning-strike.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "lightning sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub

Every sound on this site is made in your browser, from synthesis or a few CC0 recordings, and free for commercial use, no attribution required.
