Every press of New in the editor brews a different wind chime; these 12 are a fixed selection so the links stay the same.

Good for

  • Finding a secret or hidden item
  • Random encounters and events
  • Ambient accents in peaceful areas
  • Hover or highlight on special items

Tweaking tip

A longer repeat gap makes it feel like real wind; a short gap makes it feel like a magical sparkle. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew chime --count 5 --out assets/sfx/wind-chime.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "wind chime sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
