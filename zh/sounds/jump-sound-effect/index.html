关于跳跃音效：适用场景、技巧和授权

短促往上弹的"嘣"，带一口气声。比经典的方波跳跃声更柔和、更圆润，有些变体带复古 8-bit 质感，适合像素风游戏。 在编辑器里每按一次"重新生成"都会得到一个不同的跳跃；这里的 12 个是固定的，方便分享链接。

适用场景

  • 平台跳跃、二段跳
  • 踩弹簧、踩敌人
  • 小跳、闪避
  • 菜单元素弹入

调音小技巧

生成两个：低一点的给第一跳，高一点的给二段跳。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew jump --count 5 --out assets/sfx/jump.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个跳跃音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
