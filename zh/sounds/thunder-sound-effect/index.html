适用场景

  • 雷系法术、雷击

  • 戏剧性的揭晓时刻

调音小技巧

把闷雷那一层延迟零点几秒，雷就像是在远处。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew thunder --count 5 --out assets/sfx/thunder.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个天雷音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
