About these arrow sounds, uses and license

A bowstring twang followed by the hiss of the arrow cutting the air. About half of the variations end with a dull wooden thud as the arrow hits its target, so you get both the shot and the impact from one sound. Every press of New in the editor brews a different arrow; these 12 are a fixed selection so the links stay the same.

Good for

  • Archers, crossbows and ranged attacks
  • Arrow traps
  • Hit confirmation on a target
  • Skill shots and volleys

Tweaking tip

Built from real CC0 recordings of a bow, an arrow in flight and arrows hitting a target. Transpose down a few semitones for a heavier longbow. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew arrow --count 5 --out assets/sfx/arrow.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "arrow sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub

Every sound on this site is made in your browser, from synthesis or a few CC0 recordings, and free for commercial use, no attribution required.
