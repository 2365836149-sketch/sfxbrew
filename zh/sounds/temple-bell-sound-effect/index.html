免费寺钟 / 铜钟音效

大多数变体是用撞木撞响的大梵钟：先是一声闷响，然后是低沉的钟声，衰减时泛音之间慢慢"嗡嗡"地起伏。另一些是更小的铜钟，更亮、更短。需要短一点的提示音，在引擎里把尾巴剪掉就行。

适用场景

  • 任务完成、达成目标
  • 神社、寺庙、存档点的互动
  • 打坐计时、放置游戏的里程碑
  • 昼夜交替

调音小技巧

大钟庄重缓慢，留给重要时刻；频繁出现的提示用小铜钟。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew bell --count 5 --out assets/sfx/temple-bell.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个寺钟音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
