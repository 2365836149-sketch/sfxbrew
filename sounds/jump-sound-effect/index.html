About these jump sounds, uses and license

Short rising boings with a puff of air. Softer and rounder than the classic square-wave jump, with an optional retro bit-crush for pixel-art games. Every press of New in the editor brews a different jump; these 12 are a fixed selection so the links stay the same.

Good for

  • Platformer jumps and double jumps
  • Bouncing on springs or enemies
  • Hops and dodges
  • Menu items bouncing in

Tweaking tip

Generate two: a lower one for the first jump and a higher one for the double jump. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew jump --count 5 --out assets/sfx/jump.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "jump sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
