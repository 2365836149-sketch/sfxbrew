关于琵琶音效：适用场景、技巧和授权

琵琶的音色明亮、颗粒感强。每个变体随机一种弹法：单弹、琵琶最有名的轮指（同一个音快速连弹），或者扫弦（几根弦几乎同时响）。比古琴更亮、更紧张。 在编辑器里每按一次"重新生成"都会得到一个不同的琵琶；这里的 12 个是固定的，方便分享链接。

适用场景

  • 紧张、打斗的东方场景
  • 埋伏、追逐、对决的提示乐句
  • 比古琴更有力度的界面音效
  • 卡牌、策略游戏的回合开始

调音小技巧

轮指的变体特别适合"危险来了"的提示，可以和战鼓叠在一起用。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew pipa --count 5 --out assets/sfx/pipa.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个琵琶音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
