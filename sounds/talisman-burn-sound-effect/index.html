About these talisman burn sounds, uses and license

Crackling paper catching fire, with a rising tone underneath. Built for Taoist talismans and paper charms, it also works as a small fire spell or a fuse being lit. Every press of New in the editor brews a different talisman burn; these 12 are a fixed selection so the links stay the same.

Good for

  • Activating a talisman or paper charm
  • Small fire spells
  • Lighting a fuse, torch or incense
  • Burning a scroll in a cutscene

Tweaking tip

Raise the crackle layer's repeats for a longer burn. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew talisman --count 5 --out assets/sfx/talisman-burn.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "talisman burn sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp
