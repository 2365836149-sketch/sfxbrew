关于受击音效：适用场景、技巧和授权

有冲击力的打击声，由三部分组成：接触瞬间清脆的一"咔"、几十毫秒内音高迅速落下的闷响、再加一点短促的碎裂感。正是那一下快速的落音高让打击有分量。 在编辑器里每按一次"重新生成"都会得到一个不同的受击；这里的 12 个是固定的，方便分享链接。

适用场景

  • 近战打击、拳脚
  • 受到伤害
  • 物体碰撞
  • 屏幕震动的时刻

调音小技巧

暴击时把受击和一个短挥动声一起播，或者把失真调大。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew hit --count 5 --out assets/sfx/hit-punch.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个受击音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
