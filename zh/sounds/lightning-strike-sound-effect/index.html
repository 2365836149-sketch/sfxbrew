关于霹雳音效：适用场景、技巧和授权

近距离雷击的真实录音：震耳欲聋的炸裂和紧随其后的轰鸣。每个变体的音高略有升降，听起来更大、更小或更远。和缓慢酝酿的"天雷"相反，它又快又猛。 在编辑器里每按一次"重新生成"都会得到一个不同的霹雳；这里的 12 个是固定的，方便分享链接。

适用场景

  • 雷系法术、技能
  • 天劫劈下的瞬间
  • 电击陷阱、暴风雨
  • 戏剧性的转场和揭晓

调音小技巧

叠在"天雷"上就是完整的暴风雨；叠在"爆炸"上就是雷电加持的爆炸。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew lightning --count 5 --out assets/sfx/lightning-strike.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个霹雳音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
