关于符箓燃烧音效：适用场景、技巧和授权

纸张着火的噼啪声，底下垫着一个往上升的音。为道家符箓、纸符设计，也可以当小火球术、点燃引信用。 在编辑器里每按一次"重新生成"都会得到一个不同的符箓燃烧；这里的 12 个是固定的，方便分享链接。

适用场景

  • 激活符箓、纸符
  • 小型火系法术
  • 点燃引信、火把、香
  • 过场动画里烧掉卷轴

调音小技巧

把噼啪那一层的重复次数调多，就烧得更久。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew talisman --count 5 --out assets/sfx/talisman-burn.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个符箓燃烧音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
