关于确认音效：适用场景、技巧和授权

两个往上走的电钢琴音，友好、利落，适合游戏里所有"好，成了"的时刻。 在编辑器里每按一次"重新生成"都会得到一个不同的确认；这里的 12 个是固定的，方便分享链接。

适用场景

  • 确认按钮、对话框
  • 保存成功
  • 弹出提示
  • 答题答对

调音小技巧

和"错误"音效搭配使用，听起来更像一套。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew confirm --count 5 --out assets/sfx/ui-confirm.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个确认音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub

本站所有声音都在你的浏览器里实时生成（合成或少量 CC0 录音素材），可免费商用，不需要署名。
