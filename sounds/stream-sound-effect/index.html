About these stream sounds, uses and license

Five seconds of a real babbling stream recorded up close, with a seamless loop point. Each variation picks one of two passages and shifts it slightly in pitch, like a different part of the water. Every press of New in the editor brews a different stream; these 12 are a fixed selection so the links stay the same.

Good for

  • Rivers, brooks and waterfalls (from a distance)
  • Peaceful villages and forests
  • Fishing spots
  • Meditation and healing areas

Tweaking tip

Loop it and raise the volume as the player approaches the water. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew stream --count 5 --out assets/sfx/stream.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "stream sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
