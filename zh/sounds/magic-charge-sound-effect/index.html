一个慢慢涨起、带着波动的上升音，最后落在一声钟上，像能量在释放前不断聚集。在修仙游戏里是灵气汇入丹田，在动作游戏里就是蓄力攻击。

适用场景

  • 蓄力攻击、起手
  • 运功、打坐的周期提示
  • 能量条充满
  • 变身之前

调音小技巧

把第一层的起音拉长，蓄力就更久。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew qiGather --count 5 --out assets/sfx/magic-charge.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个聚气音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
