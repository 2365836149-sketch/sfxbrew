关于挥动音效：适用场景、技巧和授权

由两段往上扫的滤波噪声组成的"呼"声。足够中性，几乎所有快速动作底下都能垫。 在编辑器里每按一次"重新生成"都会得到一个不同的挥动；这里的 12 个是固定的，方便分享链接。

适用场景

  • 冲刺、闪避、挥舞
  • 界面面板滑入
  • 场景切换
  • 投掷物

调音小技巧

把扫频反过来（截止频率从高到低），就像东西在远离玩家。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew whoosh --count 5 --out assets/sfx/whoosh.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个挥动音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
