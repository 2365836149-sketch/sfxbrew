About these breakthrough sounds, uses and license

A low bell, a soft rumble and a rising arpeggio on plucked strings: the sound of reaching a new cultivation realm. It is grander than a normal level-up and is meant for rare, important moments. Every press of New in the editor brews a different breakthrough; these 12 are a fixed selection so the links stay the same.

Good for

  • Realm breakthroughs in cultivation and idle games
  • Prestige or rebirth
  • Major story milestones
  • Unlocking a new area

Tweaking tip

Use the shorter, plainer Level Up sound for frequent progress and save this one for the big steps. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew breakthrough --count 5 --out assets/sfx/cultivation-breakthrough.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "breakthrough sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
