关于爆炸音效：适用场景、技巧和授权

剧烈的爆炸：尖锐的冲击波，超低频的重拳，带失真撕裂感、在最响处停留片刻的主体轰鸣，中频的"轰"，随机落下的碎片，最后是摇晃的余震。有的变体是两三声连环爆炸。 在编辑器里每按一次"重新生成"都会得到一个不同的爆炸；这里的 12 个是固定的，方便分享链接。

适用场景

  • 炸弹、手雷、油桶
  • 摧毁敌人、建筑
  • 大招命中
  • 预告片里的重音

调音小技巧

故意做得很响，游戏里同时爆炸很多的话，把音量压低一点。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew explosion --count 5 --out assets/sfx/explosion.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个爆炸音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
