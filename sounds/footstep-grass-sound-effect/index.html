About these footstep (grass) sounds, uses and license

Single footsteps on grass and dry leaves, cut from a real recording of someone running through a forest. Each variation is one step with a soft crunch, so it lines up with your walk or run animation. Every press of New in the editor brews a different footstep (grass); these 12 are a fixed selection so the links stay the same.

Good for

  • Walking and running in fields, forests and gardens
  • Sneaking through tall grass
  • Animals and NPCs moving outdoors
  • Outdoor cutscene foley

Tweaking tip

Pick a random step for each footfall. Lower the volume for walking and keep it for running. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew footstepGrass --count 5 --out assets/sfx/footstep-grass.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "footstep (grass) sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
