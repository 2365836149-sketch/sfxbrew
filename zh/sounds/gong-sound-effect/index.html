免费铜锣音效

两种锣：大锣（tam-tam），几十个互相打架的泛音，敲完后还会"涨"起一层嗡鸣；京剧锣更小，敲完音高会明显往下掉或往上翘，京剧里角色登场就是这个声音。

适用场景

  • 战斗开始、回合宣告
  • Boss 登场
  • 搞笑或戏剧性的节点（京剧锣）
  • 比武大会场景

调音小技巧

音高往上翘的京剧锣听着俏皮，往下掉的像隆重登场。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew gong --count 5 --out assets/sfx/gong.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个铜锣音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
