关于流水音效：适用场景、技巧和授权

五秒近距离录的真实溪水声，首尾已经对接好，可以无缝循环。每个变体从两段里随机选一段，再微调一点音高，就像换了一处水流。 在编辑器里每按一次"重新生成"都会得到一个不同的流水；这里的 12 个是固定的，方便分享链接。

适用场景

  • 河流、小溪、远处的瀑布
  • 宁静的村庄和山林
  • 钓鱼点
  • 打坐、疗伤的地方

调音小技巧

循环播放，玩家离水越近音量越大。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew stream --count 5 --out assets/sfx/stream.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个流水音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
