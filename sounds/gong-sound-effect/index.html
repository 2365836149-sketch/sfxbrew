Every press of New in the editor brews a different gong; these 12 are a fixed selection so the links stay the same.

Good for

  • Battle start and round announcements
  • Boss entrances
  • Opening a menu or title screen with weight
  • Martial arts tournament scenes

Tweaking tip

Lower the vibrato for a cleaner tam-tam, or raise it for a shimmering, unstable gong. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew gong --count 5 --out assets/sfx/gong.wav

Or let Claude Code, Cursor or any MCP client add them to your project: claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp, then ask for "gong sounds".
