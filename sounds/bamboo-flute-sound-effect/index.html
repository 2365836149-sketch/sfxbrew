About these bamboo flute sounds, uses and license

Single notes in the style of the dizi, the Chinese bamboo flute: a soft fundamental with breath noise that follows the pitch, a puff at the start, gentle vibrato, and the faint buzz of the dizi's membrane that gives it its reedy edge. Every press of New in the editor brews a different bamboo flute; these 12 are a fixed selection so the links stay the same.

Good for

  • Opening a map, journal or menu
  • Scene transitions
  • Pastoral or village areas
  • Character introductions

Tweaking tip

Less vibrato sounds calmer and more modern; more vibrato sounds older and more expressive. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew flute --count 5 --out assets/sfx/bamboo-flute.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "bamboo flute sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
