适用场景

  • 雷系法术、技能
  • 天劫劈下的瞬间
  • 电击陷阱、暴风雨
  • 戏剧性的转场和揭晓

调音小技巧

叠在"天雷"上就是完整的暴风雨；叠在"爆炸"上就是雷电加持的爆炸。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew lightning --count 5 --out assets/sfx/lightning-strike.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个霹雳音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
