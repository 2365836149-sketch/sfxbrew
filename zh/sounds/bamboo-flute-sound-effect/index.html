关于竹笛音效：适用场景、技巧和授权

笛子单音：柔和的基音，跟着音高走的气声，起音时轻轻"噗"一下，带一点颤音，还有笛膜特有的那层沙沙的"嗡"，让它有了竹笛的味道。 在编辑器里每按一次"重新生成"都会得到一个不同的竹笛；这里的 12 个是固定的，方便分享链接。

适用场景

  • 打开地图、日志、菜单
  • 场景切换
  • 田园、村庄场景
  • 角色登场

调音小技巧

颤音少一些更平静、更现代；多一些更古朴、更有表现力。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew flute --count 5 --out assets/sfx/bamboo-flute.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个竹笛音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub

本站所有声音都在你的浏览器里实时生成（合成或少量 CC0 录音素材），可免费商用，不需要署名。
