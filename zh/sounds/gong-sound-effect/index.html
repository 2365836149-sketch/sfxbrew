关于铜锣音效：适用场景、技巧和授权

用真实的锣声录音和滚锣录音做成。大多数变体是一记重锣：降调就是巨大的大锣，升调就是小一些的锣；有的模仿京剧锣，敲完音高往下掉或往上翘；少数是越滚越响、最后炸开的滚锣。 在编辑器里每按一次"重新生成"都会得到一个不同的铜锣；这里的 12 个是固定的，方便分享链接。

适用场景

  • 战斗开始、回合宣告
  • Boss 登场
  • 搞笑或戏剧性的节点（京剧锣）
  • 比武大会场景

调音小技巧

音高往上翘的京剧锣听着俏皮，往下掉的像隆重登场。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew gong --count 5 --out assets/sfx/gong.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个铜锣音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
