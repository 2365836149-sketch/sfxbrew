调音小技巧

平时的进度用更短的"升级"音效，大境界才用这个。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew breakthrough --count 5 --out assets/sfx/cultivation-breakthrough.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个突破音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
