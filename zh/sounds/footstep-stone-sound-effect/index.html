关于脚步（石地）音效：适用场景、技巧和授权

走在石板地上的单个脚步：脚跟着地的闷响、鞋底的摩擦和一点沙砾声。每个变体就是一步，方便和走路动画对齐；准备几个轮流播放就不会重复。 在编辑器里每按一次"重新生成"都会得到一个不同的脚步（石地）；这里的 12 个是固定的，方便分享链接。

适用场景

  • 在石板、地砖、山路上行走或奔跑
  • 地牢、寺庙、城镇街道
  • NPC 走近的脚步
  • 过场动画的拟音

调音小技巧

共 12 步真实录音（靴子和普通鞋走在石头上）。打包下载 10 个，每一步随机挑一个播放；重甲角色可以往下移调。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew footstepStone --count 5 --out assets/sfx/footstep-stone.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个脚步（石地）音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
