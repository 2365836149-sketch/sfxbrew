关于二胡音效：适用场景、技巧和授权

二胡单音，来自真实录音：带鼻音、像人声的音色和演奏者本身的揉弦。每个变体移到五声音阶上附近的某个音，有的会滑进或滑出这个音。 在编辑器里每按一次"重新生成"都会得到一个不同的二胡；这里的 12 个是固定的，方便分享链接。

适用场景

  • 悲伤、感人的剧情
  • 角色主题、角色登场
  • 游戏失败、结束画面
  • 东方背景的对话

调音小技巧

多生成几个连着播放，就是一小段哀伤的乐句。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew erhu --count 5 --out assets/sfx/erhu.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个二胡音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
