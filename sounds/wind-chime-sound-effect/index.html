About these wind chime sounds, uses and license

A few soft, high notes from metal tubes on the pentatonic scale, each with a faint shimmer from a slightly detuned twin, like chimes moved by a breeze. Gentle enough for discovery moments that should not interrupt the player. Every press of New in the editor brews a different wind chime; these 12 are a fixed selection so the links stay the same.

Good for

  • Finding a secret or hidden item
  • Random encounters and events
  • Ambient accents in peaceful areas
  • Hover or highlight on special items

Tweaking tip

A longer repeat gap makes it feel like real wind; a short gap makes it feel like a magical sparkle. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew chime --count 5 --out assets/sfx/wind-chime.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "wind chime sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp
