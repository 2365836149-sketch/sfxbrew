调音小技巧

把钟声那一层删掉，就是单纯的冒泡声，可以当炼制中或炼制失败。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew alchemy --count 5 --out assets/sfx/potion-bubble.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个丹炉冒泡音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
