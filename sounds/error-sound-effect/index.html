About these error sounds, uses and license

Two dull, low notes made from stacked, slightly detuned voices. Clear enough to notice, soft enough not to annoy players who hear it often. Every press of New in the editor brews a different error; these 12 are a fixed selection so the links stay the same.

Good for

  • Invalid action or blocked input
  • Not enough gold, mana or energy
  • Wrong answer
  • Locked door or item

Tweaking tip

A falling repeat step sounds more like "wrong"; a flat one sounds more like "not allowed". Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew error --count 5 --out assets/sfx/error.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "error sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
