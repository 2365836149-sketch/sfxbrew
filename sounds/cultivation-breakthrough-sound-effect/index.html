Every press of New in the editor brews a different breakthrough; these 12 are a fixed selection so the links stay the same.

Good for

  • Realm breakthroughs in cultivation and idle games
  • Prestige or rebirth
  • Major story milestones
  • Unlocking a new area

Tweaking tip

Use the shorter, plainer Level Up sound for frequent progress and save this one for the big steps. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew breakthrough --count 5 --out assets/sfx/cultivation-breakthrough.wav

Or let Claude Code, Cursor or any MCP client add them to your project: claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp, then ask for "breakthrough sounds".
