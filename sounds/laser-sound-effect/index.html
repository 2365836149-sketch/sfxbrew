Every press of New in the editor brews a different laser; these 12 are a fixed selection so the links stay the same.

Good for

  • Laser guns and blasters
  • Shooting projectiles
  • Sci-fi UI accents
  • Enemy attacks in shooters

Tweaking tip

A shorter pitch time makes a snappier shot; a longer one makes a slower plasma bolt. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew laser --count 5 --out assets/sfx/laser.wav

Or let Claude Code, Cursor or any MCP client add them to your project: claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp, then ask for "laser sounds".
