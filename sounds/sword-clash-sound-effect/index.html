About these sword clash sounds, uses and license

Blade meets blade: a bright metallic clang whose tail rings and beats like real steel, plus a short scrape of the edges sliding apart. Some variations are a quick double hit. Every press of New in the editor brews a different sword clash; these 12 are a fixed selection so the links stay the same.

Good for

  • Parries and blocks
  • Duels and clashing weapons
  • Critical hits on armored enemies
  • Forging and anvil-like UI feedback

Tweaking tip

Cut from a real recording of two swords clashing. Transpose down and add reverb for heavy blades in a hall. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew swordClash --count 5 --out assets/sfx/sword-clash.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "sword clash sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
