Every press of New in the editor brews a different level up; these 12 are a fixed selection so the links stay the same.

Good for

  • Character level up
  • Achievements and trophies
  • Rewards and chests
  • Completing a stage

Tweaking tip

For the rare, big moments, use Breakthrough instead. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew levelUp --count 5 --out assets/sfx/level-up.wav

Or let Claude Code, Cursor or any MCP client add them to your project: claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp, then ask for "level up sounds".
