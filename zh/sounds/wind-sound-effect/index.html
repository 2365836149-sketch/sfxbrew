关于风音效：适用场景、技巧和授权

大约四秒的风：一阵风涌起又散去，上面飘着一缕细细的哨音，底下是低沉的呼呼声。每个变体随机是微风、阵风或狂风。 在编辑器里每按一次"重新生成"都会得到一个不同的风；这里的 12 个是固定的，方便分享链接。

适用场景

  • 山顶、沙漠、开阔的平原
  • 天气系统、暴风雨
  • 场景切换
  • 鬼魂、精怪出没的氛围

调音小技巧

两个变体错开叠在一起就是持续的风；镜头拉到高处时放一段也很有效果。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew wind --count 5 --out assets/sfx/wind.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个风音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
