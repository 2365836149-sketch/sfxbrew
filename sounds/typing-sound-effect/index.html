About these typing sounds, uses and license

A short burst of real typewriter keystrokes, three to eight keys with uneven gaps like a person typing. A quarter of the variations end with the carriage bell. Every press of New in the editor brews a different typing; these 12 are a fixed selection so the links stay the same.

Good for

  • Dialogue text appearing letter by letter
  • Terminals, hacking and computers
  • Letters, reports and notes
  • Name entry screens

Tweaking tip

For text that types itself, play a short variation every few characters instead of one per letter. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew typing --count 5 --out assets/sfx/typing.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "typing sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
