关于雨音效：适用场景、技巧和授权

大约四秒的雨声：一片沙沙的落雨、几十滴打在不同东西上的雨点，下面垫一层低低的水声。每个变体随机是小雨、中雨或大雨，首尾淡入淡出，可以循环或者交叉淡化。 在编辑器里每按一次"重新生成"都会得到一个不同的雨；这里的 12 个是固定的，方便分享链接。

适用场景

  • 天气系统、下雨的关卡
  • 村庄、山林的背景氛围
  • 悲伤或安静的剧情
  • 叠上雷声做暴风雨

调音小技巧

想要更长的雨，就拿两个变体交叉淡化循环；再叠上"天雷"就是一场暴风雨。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew rain --count 5 --out assets/sfx/rain.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个雨音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
