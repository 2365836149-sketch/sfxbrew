About these coin sounds, uses and license

Two-note metallic dings for collecting money. They are built with FM synthesis, so they sound like struck metal rather than a beeping chip, and some variants carry a light retro bit-crush. Every press of New in the editor brews a different coin; these 12 are a fixed selection so the links stay the same.

Good for

  • Collecting coins and currency
  • Purchases in a shop
  • Rewards and loot
  • Idle game income ticks

Tweaking tip

For a jackpot, generate several coins and play them a few milliseconds apart. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew coin --count 5 --out assets/sfx/coin.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "coin sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
