SFX Brew

How it works

Every sound is synthesized live in your browser with the Web Audio API. Nothing is recorded or sampled, so there is nothing to license. Pick a preset, press Mutate until it fits, then fine-tune the layers.

Made for AI-assisted game development

Copy JS gives you a small, dependency-free snippet that plays the exact same sound. Paste it into a game written with Claude, Cursor or by hand: no audio files to load or host.

Let your AI agent make the sounds

The same engine runs as a local MCP server: no API key, no network, no cost per sound. In Claude Code:

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Then ask "add a coin sound and a hit sound to my game". Prefer the command line? npx sfxbrew coin --out assets/sfx/coin.wav. Details for agents: llms.txt.

Eastern sounds

Wuxia and xianxia games need sounds that stock libraries rarely have: sword qi, guqin plucks, temple bells, gongs, talismans and heavenly tribulation thunder. Melodic presets use the pentatonic scale, so every combination stays in tune.

原理

所有声音都在你的浏览器里用 Web Audio 实时合成，没有录音也没有采样，不存在版权问题。选一个预设，点「变体」直到满意，再细调各个音层。

为 AI 写游戏而做

「复制 JS」会给你一小段不依赖任何库的代码，播放出来和这里听到的完全一样。粘进用 Claude、Cursor 或手写的游戏里就能用，不用加载或托管音频文件。

让 AI agent 直接生成音效

同一个合成引擎也能作为本地 MCP 服务运行：不需要 API key、不联网、每个声音零成本。在 Claude Code 里：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

然后说"给我的游戏加一个金币音效和一个受击音效"就行。也可以用命令行：npx sfxbrew coin --out assets/sfx/coin.wav。给 agent 看的说明：llms.txt。

东方音效

武侠、修仙游戏需要的剑气、古琴、寺钟、铜锣、符箓、天雷，在普通音效库里很难找到。有旋律的预设都用五声音阶，怎么组合都不会走调。
