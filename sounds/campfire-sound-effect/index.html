About these campfire sounds, uses and license

Five seconds of a real campfire crackling on a quiet night. The end is crossfaded into the start, so it loops without a seam; some variations add a few extra pops of burning wood. Every press of New in the editor brews a different campfire; these 12 are a fixed selection so the links stay the same.

Good for

  • Camps, rest points and save spots
  • Hearths, forges and kitchens
  • Torches and braziers (quieter)
  • Night scenes outdoors

Tweaking tip

Loop it under your scene and fade the volume with distance from the fire. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew campfire --count 5 --out assets/sfx/campfire.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "campfire sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
