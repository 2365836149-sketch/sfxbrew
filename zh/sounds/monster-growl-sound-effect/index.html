关于怪物低吼音效：适用场景、技巧和授权

真实的低吼和咆哮录音，音高随机压低或抬高，再垫一层低频的胸腔共鸣。音低的变体像巨兽、龙，音高的像小型怪物。 在编辑器里每按一次"重新生成"都会得到一个不同的怪物低吼；这里的 12 个是固定的，方便分享链接。

适用场景

  • 怪物、野兽、龙
  • Boss 登场、狂暴阶段
  • 敌人发现玩家
  • 修仙游戏里的妖兽、灵兽

调音小技巧

再往下移调、加大混响，就像山洞里的巨型 Boss。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew monsterGrowl --count 5 --out assets/sfx/monster-growl.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个怪物低吼音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
