关于战鼓音效：适用场景、技巧和授权

用中国大鼓（dagu）的真实录音编排的擂鼓：鼓心的重击、鼓边的回响、鼓框的脆响，组成匀速的行军鼓、越滚越响的擂鼓，或者越敲越快、越敲越猛的催阵鼓。每一下都余音数秒、前后交叠，在大厅里回荡。 在编辑器里每按一次"重新生成"都会得到一个不同的战鼓；这里的 12 个是固定的，方便分享链接。

适用场景

  • 开战、冲锋
  • 攻城、Boss 换阶段
  • 对决前的紧张蓄势
  • 胜利、鼓舞士气

调音小技巧

催阵鼓的最后接一声锣或一道霹雳，就是很有气势的开战。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew drum --count 5 --out assets/sfx/war-drum.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个战鼓音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
