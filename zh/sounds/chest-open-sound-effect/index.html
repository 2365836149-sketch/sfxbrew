关于开宝箱音效：适用场景、技巧和授权

真实录音：木箱、旧箱子"吱呀"一声被打开。有些变体最后还有一串风铃般的闪光声，就是经典的"发现宝物"时刻。 在编辑器里每按一次"重新生成"都会得到一个不同的开宝箱；这里的 12 个是固定的，方便分享链接。

适用场景

  • 开宝箱、拾取战利品
  • 木箱、柜子、门
  • 奖励结算画面
  • 密室被打开

调音小技巧

普通箱子用只有吱呀声的变体，稀有宝物才用带闪光的。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew chestOpen --count 5 --out assets/sfx/chest-open.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个开宝箱音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
