About these energy charge sounds, uses and license

A swelling, wobbling rise that ends in a bell, like energy gathering before release. In cultivation games it is qi flowing into the dantian; in any action game it is a charged attack. Every press of New in the editor brews a different energy charge; these 12 are a fixed selection so the links stay the same.

Good for

  • Charged attacks and wind-ups
  • Channelling and meditation ticks
  • Power gauge filling up
  • Before a transformation

Tweaking tip

Stretch the attack of the first layer to make the charge longer. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew qiGather --count 5 --out assets/sfx/magic-charge.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "energy charge sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
