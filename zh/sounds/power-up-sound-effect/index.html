适用场景

  • 吃到强化道具

  • 能量条充满

调音小技巧

每次生成会随机选两种风格之一，多生成几个比较一下。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew powerUp --count 5 --out assets/sfx/power-up.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个强化音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
