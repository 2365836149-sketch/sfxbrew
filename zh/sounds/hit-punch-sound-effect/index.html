免费打击 / 受击音效

适用场景

  • 近战打击、拳脚
  • 受到伤害
  • 物体碰撞
  • 屏幕震动的时刻

调音小技巧

暴击时把受击和一个短挥动声一起播，或者把失真调大。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew hit --count 5 --out assets/sfx/hit-punch.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个受击音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
