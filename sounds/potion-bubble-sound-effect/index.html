Every press of New in the editor brews a different potion bubble; these 12 are a fixed selection so the links stay the same.

Good for

  • Potion brewing and alchemy
  • Crafting success
  • Cooking or mixing minigames
  • Consuming a potion

Tweaking tip

Remove the bell layer to get a plain bubbling sound for a failed or ongoing brew. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew alchemy --count 5 --out assets/sfx/potion-bubble.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "potion bubble sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
