关于拾取音效：适用场景、技巧和授权

快速往上挑的一声，顶上带一点闪光。足够短，一分钟听几十次也不会腻。 在编辑器里每按一次"重新生成"都会得到一个不同的拾取；这里的 12 个是固定的，方便分享链接。

适用场景

  • 拾取道具、收集品
  • 宝石、灵珠、经验值
  • 放进背包
  • 鼠标悬停在掉落物上

调音小技巧

盔甲这类重物品把音高调低，小宝石调高。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew pickup --count 5 --out assets/sfx/item-pickup.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个拾取音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
