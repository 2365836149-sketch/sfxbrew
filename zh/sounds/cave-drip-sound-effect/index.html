关于洞穴滴水音效：适用场景、技巧和授权

洞里某处水滴落进水洼：每一滴是一声短促、往上扬的"叮咚"，带着很长的洞穴混响和轻轻的回声，下面是一层幽暗的空间底噪。 在编辑器里每按一次"重新生成"都会得到一个不同的洞穴滴水；这里的 12 个是固定的，方便分享链接。

适用场景

  • 山洞、石窟、地牢
  • 秘境、密室
  • 安静又紧张的探索
  • 地下水道

调音小技巧

每隔几秒随机音量放一个变体，洞里就不会听出循环感。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew caveDrip --count 5 --out assets/sfx/cave-drip.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个洞穴滴水音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
