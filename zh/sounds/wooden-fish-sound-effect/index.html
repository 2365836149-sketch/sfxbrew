关于木鱼音效：适用场景、技巧和授权

僧人诵经时敲的木鱼，空心木头"笃"的一声。短促、木质，每个变体敲一到三下。"敲电子木鱼"类的点击游戏让这个声音本身就很有梗。 在编辑器里每按一次"重新生成"都会得到一个不同的木鱼；这里的 12 个是固定的，方便分享链接。

适用场景

  • 点击类、放置类游戏的每一下点击
  • 寺庙、诵经场景
  • 钟表滴答、倒计时
  • 带东方味道的界面点击

调音小技巧

只敲一下的变体适合连续点击；敲两下的适合当"下一步"或"确认"。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew woodfish --count 5 --out assets/sfx/wooden-fish.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个木鱼音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
