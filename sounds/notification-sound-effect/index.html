About these notification sounds, uses and license

Two soft, marimba-like dings that step up a little, the friendly kind of alert that says something happened without startling the player. The notes stay on the pentatonic scale. Every press of New in the editor brews a different notification; these 12 are a fixed selection so the links stay the same.

Good for

  • Messages, toasts and pop-ups
  • Quest updates and new items in the log
  • Friend online, mail received
  • Timers finishing

Tweaking tip

For an important alert, raise the pitch and shorten the gap between the two notes. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew notify --count 5 --out assets/sfx/notification.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "notification sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
