About these war drum sounds, uses and license

Rolling Chinese war drums built from real recordings of a dagu, the big Chinese bass drum: heavy center strokes, ringing edge strokes and rim shots, arranged into a steady march, a thundering roll that keeps growing, or a call to battle that speeds up until it hammers. Every hit rings for seconds and overlaps the next, in a large hall. Every press of New in the editor brews a different war drum; these 12 are a fixed selection so the links stay the same.

Good for

  • Battle start and army charges
  • Sieges and boss phases
  • Rising tension before a duel
  • Victory or rally moments

Tweaking tip

End a build-up with a gong or a Lightning strike for a dramatic battle opening. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew drum --count 5 --out assets/sfx/war-drum.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "war drum sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
