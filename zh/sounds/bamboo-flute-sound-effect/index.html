适用场景

  • 打开地图、日志、菜单
  • 场景切换

  • 角色登场

调音小技巧

颤音少一些更平静、更现代；多一些更古朴、更有表现力。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew flute --count 5 --out assets/sfx/bamboo-flute.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个竹笛音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
