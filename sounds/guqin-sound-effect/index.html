Free Guqin Pluck Sound Effects

Single plucked notes in the spirit of the guqin, the seven-string Chinese zither. Every note sits on the pentatonic scale and some slide up or down like a player sliding along the string, so any two of them sound good played one after another.

Every press of New in the editor brews a different guqin pluck; these 12 are a fixed selection so the links stay the same.

Good for

  • Calm UI taps in an Eastern-themed game
  • Dialogue text ticks
  • Meditation, cultivation or crafting feedback
  • Short stingers between scenes

Tweaking tip

Generate a pack of ten and play them in sequence on repeated actions: because they share a scale, rapid taps turn into a small melody. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew guqin --count 5 --out assets/sfx/guqin.wav

Or let Claude Code, Cursor or any MCP client add them to your project: claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp, then ask for "guqin pluck sounds".
