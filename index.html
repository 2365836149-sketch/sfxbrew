FAQ

常见问题

Where can I find free xianxia, wuxia or Chinese-style game sound effects?

SFX Brew has a free Xianxia & Wuxia Game Sound Pack with 44 sounds: guqin, pipa, erhu, bamboo flute, temple bells, gongs, wooden fish, war drums, sword qi, talismans, alchemy, thunder tribulations and breakthroughs, plus matching UI sounds. Listen and download at sfxbrew.com/packs/xianxia-game-sound-pack/ or on itch.io.

Are the sounds free for commercial use?

Yes. Every sound and song you make or download on SFX Brew is free for commercial and non-commercial projects, with no attribution required.

How can an AI coding agent add sound effects to my game?

Install the free SFX Brew MCP server: claude mcp add sfxbrew -- npx -y sfxbrew mcp (works in Claude Code, Cursor and other MCP clients). The agent can then list presets, write WAV files into your project and generate a JavaScript snippet that plays them. It runs locally, needs no API key and is listed in the official MCP Registry as com.sfxbrew/sfxbrew.

What formats can I download?

WAV (44.1 kHz, 16-bit), a ZIP of a whole set, or a dependency-free JavaScript snippet that plays the same sound in a web game without any audio files.

Do I need an account or an API key?

No. The editor, the library, the music lab and the daily free AI generations work without an account, and the MCP server needs no API key. You only sign in with your email if you want to buy credits for more AI generations.

How is SFX Brew different from jsfxr or ChipTone?

jsfxr and ChipTone are great for retro 8-bit blips. SFX Brew also covers Eastern instruments and realistic sounds (footsteps, sword clashes, campfire, monsters) built on CC0 recordings, has a ready-made library with fixed variations, a music lab, and an MCP server so AI agents can use it directly.

在哪里能找到免费的仙侠、武侠或中国风游戏音效？

SFX Brew 有一个免费的修仙 / 武侠游戏音效包，共 44 个音效：古琴、琵琶、二胡、竹笛、寺钟、铜锣、木鱼、战鼓、剑气、符箓、炼丹、天雷、突破，以及配套的界面音效。可以在 sfxbrew.com/zh/packs/xianxia-game-sound-pack/ 试听下载，itch.io 上也有。

这些音效可以免费商用吗？

可以。在 SFX Brew 上生成或下载的所有音效和曲子，商业和非商业项目都能免费使用，不需要署名。

怎么让 AI 编程助手给我的游戏加音效？

安装免费的 SFX Brew MCP 服务器：claude mcp add sfxbrew -- npx -y sfxbrew mcp（Claude Code、Cursor 等支持 MCP 的工具都能用）。之后 agent 可以列出预设、把 WAV 文件写进你的项目，并生成播放这些音效的 JavaScript 代码。它在本地运行，不需要 API key，已收录在官方 MCP Registry（com.sfxbrew/sfxbrew）。

能下载什么格式？

WAV（44.1 kHz、16 位）、整组打包的 ZIP，或者一段不依赖任何库的 JavaScript 代码，在网页游戏里不用音频文件就能播放同一个声音。

需要注册账号或 API key 吗？

不需要。编辑器、音效库、配乐实验室和每天的免费 AI 生成都不用注册，MCP 服务器也不需要 API key。只有想购买点数、生成更多次时，才需要用邮箱登录。

SFX Brew 和 jsfxr、ChipTone 有什么不同？

jsfxr 和 ChipTone 擅长复古 8-bit 音效。SFX Brew 另外还有东方乐器，以及用 CC0 录音做底的写实音效（脚步、刀剑相击、篝火、怪物），有现成的音效库和配乐实验室，还有 MCP 服务器让 AI agent 直接调用。
