Every press of New in the editor brews a different item pickup; these 12 are a fixed selection so the links stay the same.

Good for

  • Picking up items and collectibles
  • Gems, orbs and experience points
  • Adding to inventory
  • Hover feedback on loot

Tweaking tip

Lower the pitch for heavier items like armour, raise it for small gems. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew pickup --count 5 --out assets/sfx/item-pickup.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "item pickup sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
