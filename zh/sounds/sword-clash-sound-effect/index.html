关于刀剑相击音效：适用场景、技巧和授权

兵刃相碰：清亮的金属"锵"，余音像真钢铁一样带点颤动，再加一下刀刃擦开的"嚓"。有些变体是连着两下。 在编辑器里每按一次"重新生成"都会得到一个不同的刀剑相击；这里的 12 个是固定的，方便分享链接。

适用场景

  • 格挡、招架
  • 比武、兵器碰撞
  • 打在重甲上的暴击
  • 锻造、铁匠铺之类的反馈

调音小技巧

切自两把真剑对砍的录音。移调往下、混响加大，就像在大殿里两把重剑相交。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew swordClash --count 5 --out assets/sfx/sword-clash.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个刀剑相击音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
