关于施法音效：适用场景、技巧和授权

一阵往上扬的风声，叠着一串闪烁的钟音和短短的回声。一听就知道"有法术发动了"，又不偏向任何一种元素。 在编辑器里每按一次"重新生成"都会得到一个不同的施法；这里的 12 个是固定的，方便分享链接。

适用场景

  • 施法、释放技能
  • 增益、治疗、附魔
  • 解锁新能力
  • 传送门、传送

调音小技巧

钟音层重复次数多一些，闪烁就更长；把每次升降设成负数，就变成往下走、更阴暗的法术。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew spell --count 5 --out assets/sfx/magic-spell.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个施法音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
