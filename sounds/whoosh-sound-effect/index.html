About these whoosh sounds, uses and license

Airy swooshes made from two filtered noise bands sweeping upward. Neutral enough to sit under almost any fast movement. Every press of New in the editor brews a different whoosh; these 12 are a fixed selection so the links stay the same.

Good for

  • Dashes, dodges and swings
  • UI panels sliding in
  • Scene transitions
  • Thrown objects

Tweaking tip

Reverse the sweep (high cutoff to low) for something moving away from the player. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew whoosh --count 5 --out assets/sfx/whoosh.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "whoosh sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
