About these spell cast sounds, uses and license

A rising whoosh topped by a sparkling run of bell notes and a short echo. It reads instantly as "something magical just happened" without sounding like any specific element. Every press of New in the editor brews a different spell cast; these 12 are a fixed selection so the links stay the same.

Good for

  • Casting a spell or using a skill
  • Buffs, heals and enchantments
  • Unlocking an ability
  • Portals and teleports

Tweaking tip

More repeats in the bell layer make a longer shimmer; a negative repeat step turns it into a falling, darker spell. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew spell --count 5 --out assets/sfx/magic-spell.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "spell cast sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
