关于天雷音效：适用场景、技巧和授权

酝酿中的滚滚雷声：一声雷经过远近不同的路径传到耳边，所以闷雷在随机时刻一阵阵滚来，底下垫着一层摇晃的超低频。有的变体在近处、开头有几声炸裂，有的只是远处的闷雷。闪电劈下来的那一下，请用"霹雳"。 在编辑器里每按一次"重新生成"都会得到一个不同的天雷；这里的 12 个是固定的，方便分享链接。

适用场景

  • 修仙游戏里天劫的酝酿
  • 暴风雨、天气氛围
  • Boss 登场前的不祥预兆
  • 和"霹雳"一起用，就是完整的雷击

调音小技巧

先播"霹雳"，稍后接这个，就是一道闪电劈下、雷声滚滚而去。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew thunder --count 5 --out assets/sfx/thunder.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个天雷音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
