关于落地音效：适用场景、技巧和授权

角色跳起后着地的那一声，来自真实录音：落在硬地板上、普通地面上，还有一段踩断了树枝。有些变体垫了一下低频的"咚"，适合块头大的角色。 在编辑器里每按一次"重新生成"都会得到一个不同的落地；这里的 12 个是固定的，方便分享链接。

适用场景

  • 跳跃或掉落后着地
  • 重型敌人跳进场地
  • 蹬墙跳、二段跳
  • 道具、箱子掉在地上

调音小技巧

和"跳跃"配着用：起跳时放跳跃，落下时放落地。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew land --count 5 --out assets/sfx/landing.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个落地音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
