About these shield block sounds, uses and license

An attack stopped by a shield: a real metal impact layered with a deep, synthesized thud of the shield body and a short wooden knock. Heavier and duller than a sword clash. Every press of New in the editor brews a different shield block; these 12 are a fixed selection so the links stay the same.

Good for

  • Blocking and guarding
  • Perfect parry or guard break
  • Hits on armored or shielded enemies
  • Defensive skills

Tweaking tip

Transpose down for a big tower shield; turn the thud down for a small buckler. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew shieldBlock --count 5 --out assets/sfx/shield-block.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "shield block sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
