关于射箭音效：适用场景、技巧和授权

弓弦"嘣"的一声，接着箭破空的"嗖"。大约一半变体最后有一声闷闷的"笃"，是箭扎进靶子或木头里，一个声音就包含了射出和命中。 在编辑器里每按一次"重新生成"都会得到一个不同的射箭；这里的 12 个是固定的，方便分享链接。

适用场景

  • 弓手、弩和各种远程攻击
  • 机关暗箭
  • 命中靶子的反馈
  • 技能连射、箭雨

调音小技巧

用的是真实的 CC0 录音：弓弦、箭飞过和中靶。想要更沉的长弓，把移调往下调几个半音。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew arrow --count 5 --out assets/sfx/arrow.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个射箭音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
