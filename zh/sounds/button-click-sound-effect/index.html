适用场景

  • 按钮、开关
  • 菜单导航
  • 打字、数字键盘
  • 选择卡牌、格子

调音小技巧

"返回"用低一点的点击，"下一步"用高一点的，菜单就有了方向感。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew click --count 5 --out assets/sfx/button-click.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个点击音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
