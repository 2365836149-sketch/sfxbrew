关于格挡音效：适用场景、技巧和授权

一击被盾牌挡下：真实录音里的金属撞击，叠上合成的盾身闷响和一下短促的木头声。比刀剑相击更沉、更钝。 在编辑器里每按一次"重新生成"都会得到一个不同的格挡；这里的 12 个是固定的，方便分享链接。

适用场景

  • 举盾格挡、防御
  • 完美招架、破防
  • 打在带盾或重甲的敌人身上
  • 防御类技能

调音小技巧

大盾就往下移调；小圆盾就把闷响那一层调小。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew shieldBlock --count 5 --out assets/sfx/shield-block.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个格挡音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
