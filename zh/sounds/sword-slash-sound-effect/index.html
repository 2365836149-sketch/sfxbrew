调音小技巧

想要更沉的兵器，就把噪声层的截止频率调低、余鸣缩短；想要更"仙"，就把混响调大。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew swordQi --count 5 --out assets/sfx/sword-slash.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个剑气音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
