Every press of New in the editor brews a different talisman burn; these 12 are a fixed selection so the links stay the same.

Good for

  • Activating a talisman or paper charm
  • Small fire spells
  • Lighting a fuse, torch or incense
  • Burning a scroll in a cutscene

Tweaking tip

Raise the crackle layer's repeats for a longer burn. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew talisman --count 5 --out assets/sfx/talisman-burn.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "talisman burn sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
