Free Guqin Sound Effects

Single notes of the guqin, the seven-string Chinese zither, made with a physically modelled string rather than a synth tone. Each variation is played one of three ways: an open string with a deep, woody ring, a pressed note where the finger slides along the string after the pluck, or a pure, bell-like harmonic. All notes sit on the pentatonic scale.

Every press of New in the editor brews a different guqin; these 12 are a fixed selection so the links stay the same.

Good for

  • Calm UI taps in an Eastern-themed game
  • Dialogue text ticks
  • Meditation, cultivation or crafting feedback
  • Short stingers between scenes

Tweaking tip

Generate a pack and play the notes in sequence on repeated actions: because they share a scale, rapid taps turn into a small melody. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew guqin --count 5 --out assets/sfx/guqin.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "guqin sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
