关于强化音效：适用场景、技巧和授权

要么是一串快速上行的琶音，要么是一个慢慢涨起来的扫频。两种都能在一秒内告诉玩家"你变强了"。 在编辑器里每按一次"重新生成"都会得到一个不同的强化；这里的 12 个是固定的，方便分享链接。

适用场景

  • 吃到强化道具
  • 升级装备、获得增益
  • 连击、连胜里程碑
  • 能量条充满

调音小技巧

每次生成会随机选两种风格之一，多生成几个比较一下。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew powerUp --count 5 --out assets/sfx/power-up.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个强化音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
