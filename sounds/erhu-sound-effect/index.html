Free Erhu Sound Effects

Single bowed notes of the erhu, the two-string Chinese fiddle, with its nasal, voice-like tone, wide vibrato and the occasional slide into the note. It carries emotion better than any other sound here.

Every press of New in the editor brews a different erhu; these 12 are a fixed selection so the links stay the same.

Good for

  • Sad or emotional story beats
  • Character themes and introductions
  • Game over or defeat screens
  • Dialogue with an Eastern setting

Tweaking tip

A slower vibrato sounds more sorrowful; a faster one sounds more agitated. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew erhu --count 5 --out assets/sfx/erhu.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "erhu sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
