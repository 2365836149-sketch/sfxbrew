About these thunder sounds, uses and license

Brewing, rolling thunder: rumbles arrive at random moments from different distances, the way one thunderclap reaches you along many paths, over a low, wobbling bed. Some variations are close with a few cracks up front, others are distant rumble only. For the strike itself, use Lightning. Every press of New in the editor brews a different thunder; these 12 are a fixed selection so the links stay the same.

Good for

  • Heavenly tribulation building up in cultivation games
  • Storm ambience and weather
  • Ominous moments before a boss
  • Combine with Lightning for a full strike

Tweaking tip

Play Lightning first and this a moment later to get a strike followed by its echoing rumble. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew thunder --count 5 --out assets/sfx/thunder.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "thunder sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
