Every press of New in the editor brews a different error; these 12 are a fixed selection so the links stay the same.

Good for

  • Invalid action or blocked input
  • Not enough gold, mana or energy
  • Wrong answer
  • Locked door or item

Tweaking tip

A falling repeat step sounds more like "wrong"; a flat one sounds more like "not allowed". Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew error --count 5 --out assets/sfx/error.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "error sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
