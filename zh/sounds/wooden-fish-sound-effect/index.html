适用场景

  • 点击类、放置类游戏的每一下点击
  • 寺庙、诵经场景
  • 钟表滴答、倒计时
  • 带东方味道的界面点击

调音小技巧

只敲一下的变体适合连续点击；敲两下的适合当"下一步"或"确认"。点任意一个变体的"编辑"，就能用滑杆细调。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew woodfish --count 5 --out assets/sfx/wooden-fish.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个木鱼音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
