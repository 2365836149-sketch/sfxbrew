About these button click sounds, uses and license

Very short tactile ticks for interface buttons: a tiny burst of filtered noise for the contact plus a quick tonal body. Under 50 milliseconds, so they never lag behind the click. Every press of New in the editor brews a different button click; these 12 are a fixed selection so the links stay the same.

Good for

  • Button presses and toggles
  • Menu navigation
  • Typing or keypad input
  • Selecting cards or tiles

Tweaking tip

Pair a lower click for "back" with a higher one for "next" to give menus a sense of direction. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew click --count 5 --out assets/sfx/button-click.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "button click sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp
