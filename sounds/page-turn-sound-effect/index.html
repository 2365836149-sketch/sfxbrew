About these page turn sounds, uses and license

Real recordings of book pages being turned, from a thin page to the heavier pages of an old book. Each variation is a single turn. Every press of New in the editor brews a different page turn; these 12 are a fixed selection so the links stay the same.

Good for

  • Journals, quest logs and codices
  • Spell books and manuals
  • Menu tabs and inventory pages
  • Story books and tutorials

Tweaking tip

Use it for any UI that flips between pages; it reads as "next" without a beep. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew pageTurn --count 5 --out assets/sfx/page-turn.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "page turn sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
