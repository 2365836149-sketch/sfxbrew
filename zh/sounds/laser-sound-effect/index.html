关于激光音效：适用场景、技巧和授权

往下掉的"咻"，用 FM 合成加两个微微走调的声音，有咬劲但不像纯方波那么刺耳。 在编辑器里每按一次"重新生成"都会得到一个不同的激光；这里的 12 个是固定的，方便分享链接。

适用场景

  • 激光枪、能量枪
  • 发射子弹、飞行物
  • 科幻风格的界面点缀
  • 射击游戏里的敌人攻击

调音小技巧

音高滑动时长短一些，枪声更干脆；长一些，像一发慢速的等离子弹。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew laser --count 5 --out assets/sfx/laser.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个激光音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
