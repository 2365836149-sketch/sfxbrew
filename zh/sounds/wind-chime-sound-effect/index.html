关于风铃音效：适用场景、技巧和授权

几声轻柔、高亢的金属管音，五声音阶，每个音旁边还有一个微微走调的"影子"，听起来在轻轻闪烁，像被风吹动的风铃。足够温和，适合不打断玩家的发现时刻。 在编辑器里每按一次"重新生成"都会得到一个不同的风铃；这里的 12 个是固定的，方便分享链接。

适用场景

  • 发现秘密、隐藏物品
  • 奇遇、随机事件
  • 宁静区域的环境点缀
  • 鼠标悬停在特殊物品上

调音小技巧

重复间隔长一些更像真的风；短一些更像魔法的闪光。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew chime --count 5 --out assets/sfx/wind-chime.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个风铃音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
