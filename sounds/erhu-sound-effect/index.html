About these erhu sounds, uses and license

Single notes of the erhu, the two-string Chinese fiddle, from real recordings: the nasal, voice-like tone and the player's own vibrato. Each variation is moved to a nearby note of the pentatonic scale, and some slide into or out of the note. Every press of New in the editor brews a different erhu; these 12 are a fixed selection so the links stay the same.

Good for

  • Sad or emotional story beats
  • Character themes and introductions
  • Game over or defeat screens
  • Dialogue with an Eastern setting

Tweaking tip

Generate a few and play them one after another for a short, sad phrase. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew erhu --count 5 --out assets/sfx/erhu.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "erhu sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
