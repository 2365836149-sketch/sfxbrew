About these wind sounds, uses and license

About four seconds of wind: a gust that swells and dies away, a thin whistle riding on top and a low rumble underneath. Each variation is a light breeze, a gust or a strong wind. Every press of New in the editor brews a different wind; these 12 are a fixed selection so the links stay the same.

Good for

  • Mountain tops, deserts and open plains
  • Weather systems and storms
  • Transitions between scenes
  • Spirit or ghost ambience

Tweaking tip

Layer two variations with an offset for a continuous wind, or play one when the camera moves somewhere high. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew wind --count 5 --out assets/sfx/wind.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "wind sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
