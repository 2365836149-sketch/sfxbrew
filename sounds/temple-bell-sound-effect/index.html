Free Temple Bell Sound Effects

Most variations are a large temple bell struck by a wooden beam: a soft thud, then a deep tone whose overtones beat slowly against each other as it fades. Others are smaller bronze bells with a brighter, shorter ring. Trim the tail in your engine if you need a short notification.

Every press of New in the editor brews a different temple bell; these 12 are a fixed selection so the links stay the same.

Good for

  • Quest complete or objective reached
  • Shrine, temple and save-point interactions
  • Meditation timers and idle-game milestones
  • Day or night transitions

Tweaking tip

The large bells are slow and solemn; save them for important moments and use the small bronze bells for frequent ones. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew bell --count 5 --out assets/sfx/temple-bell.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "temple bell sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
