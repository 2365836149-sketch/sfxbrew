关于升级音效：适用场景、技巧和授权

一串明亮的琶音，落在一个柔和的和弦和一声钟上。有庆祝感但不是完整的号角，玩家频繁升级也不会腻。 在编辑器里每按一次"重新生成"都会得到一个不同的升级；这里的 12 个是固定的，方便分享链接。

适用场景

  • 角色升级
  • 成就、奖杯
  • 奖励、开宝箱
  • 通关

调音小技巧

少见的大时刻改用"突破"。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew levelUp --count 5 --out assets/sfx/level-up.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个升级音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp

免费的 agent skill，教你的 agent 什么时候、怎么用： Agensi · GitHub
