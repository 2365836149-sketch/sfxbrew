关于篝火音效：适用场景、技巧和授权

五秒真实的篝火录音，安静的夜里木柴噼啪作响。结尾已经和开头交叉淡化过，循环播放没有接缝；有些变体还多加了几下木柴爆裂声。 在编辑器里每按一次"重新生成"都会得到一个不同的篝火；这里的 12 个是固定的，方便分享链接。

适用场景

  • 营地、休息点、存档点
  • 灶台、炼器炉、厨房
  • 火把、火盆（音量调小）
  • 野外的夜晚

调音小技巧

循环放在场景底下，离火越远音量越小。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew campfire --count 5 --out assets/sfx/campfire.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个篝火音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
