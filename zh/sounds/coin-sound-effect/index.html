关于金币音效：适用场景、技巧和授权

收钱时"叮叮"两声的金属音。用 FM 合成，听起来像敲在金属上，而不是芯片的"哔哔"；有些变体带一点复古的 8-bit 颗粒感。 在编辑器里每按一次"重新生成"都会得到一个不同的金币；这里的 12 个是固定的，方便分享链接。

适用场景

  • 捡金币、获得货币
  • 商店购买
  • 奖励、掉落
  • 放置游戏的收入跳动

调音小技巧

想要"中大奖"的效果，就生成几个金币音，间隔几毫秒一起播。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew coin --count 5 --out assets/sfx/coin.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个金币音效"：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
