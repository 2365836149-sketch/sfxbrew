Every press of New in the editor brews a different lightning; these 12 are a fixed selection so the links stay the same.

Good for

  • Lightning spells and skills
  • The moment a heavenly tribulation strikes
  • Electric traps and storms
  • Dramatic cuts and reveals

Tweaking tip

Layer it over a Thunder rumble for the full storm, or over an Explosion for a lightning-powered blast. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew lightning --count 5 --out assets/sfx/lightning-strike.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "lightning sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
