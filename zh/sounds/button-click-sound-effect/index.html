关于点击音效：适用场景、技巧和授权

给界面按钮用的极短"咔哒"：一小段滤波噪声模拟接触，加一个很快的音调。不到 50 毫秒，永远不会比点击慢半拍。 在编辑器里每按一次"重新生成"都会得到一个不同的点击；这里的 12 个是固定的，方便分享链接。

适用场景

  • 按钮、开关
  • 菜单导航
  • 打字、数字键盘
  • 选择卡牌、格子

调音小技巧

"返回"用低一点的点击，"下一步"用高一点的，菜单就有了方向感。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew click --count 5 --out assets/sfx/button-click.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个点击音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
