For AI coding agents

给 AI 写代码用

One command gives Claude Code, Cursor and other MCP clients a free, local sound generator:

一条命令，Claude Code、Cursor 等支持 MCP 的工具就有了一个免费、本地的音效生成器：

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp

Or from the command line: npx sfxbrew coin --out assets/sfx/coin.wav. Teach your agent when to use it with the free skill on Agensi or SKILL.md on GitHub. Details for agents: llms.txt.

也可以用命令行：npx sfxbrew coin --out assets/sfx/coin.wav。想让 agent 知道什么时候用，可以装 Agensi 上的免费 skill 或 GitHub 上的 SKILL.md。给 agent 看的说明：llms.txt。

How it works

原理

Everything is synthesized live with the Web Audio API. A few sounds (war drum, lightning, gong, erhu) build on short CC0 recordings. Melodic sounds use the pentatonic scale, so they always stay in tune. The JavaScript export plays the same sound in your game with no audio files.

所有声音都用 Web Audio 实时合成，少数（战鼓、霹雳、铜锣、二胡）用到了很短的 CC0 录音。有旋律的声音都用五声音阶，怎么组合都不走调。导出的 JavaScript 不需要任何音频文件，在游戏里就能播放同一个声音。

Eastern sounds

东方音效

Wuxia and xianxia games need sounds stock libraries rarely have: sword qi, guqin, pipa, erhu, temple bells, gongs, war drums, talismans and heavenly thunder.

武侠、修仙游戏需要的剑气、古琴、琵琶、二胡、寺钟、铜锣、战鼓、符箓、天雷，在普通音效库里很难找到。
