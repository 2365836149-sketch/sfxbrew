About these ui confirm sounds, uses and license

Two pleasant electric-piano notes going up. Friendly and quick, for any moment the game says "yes, that worked". Every press of New in the editor brews a different ui confirm; these 12 are a fixed selection so the links stay the same.

Good for

  • Confirm buttons and dialogs
  • Save successful
  • Toast notifications
  • Correct answers in quizzes

Tweaking tip

Use it together with the Error sound from the same session so they feel like a matching set. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew confirm --count 5 --out assets/sfx/ui-confirm.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "ui confirm sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
