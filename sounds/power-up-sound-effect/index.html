Every press of New in the editor brews a different power-up; these 12 are a fixed selection so the links stay the same.

Good for

  • Collecting a power-up
  • Upgrades and buffs
  • Combo or streak milestones
  • Filling a gauge

Tweaking tip

Each generation picks one of the two styles at random; generate a few to compare. Open any variant with Edit to change it with sliders.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew powerUp --count 5 --out assets/sfx/power-up.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "power-up sounds":

claude mcp add sfxbrew -- npx -y -p sfxbrew sfxbrew-mcp
