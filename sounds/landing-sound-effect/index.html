About these land sounds, uses and license

The thud of a character landing after a jump, from real recordings: on a hard floor, on the ground and onto some snapping sticks. Some variations add a low thump for heavier characters. Every press of New in the editor brews a different land; these 12 are a fixed selection so the links stay the same.

Good for

  • Landing after a jump or fall
  • Heavy enemies dropping into the arena
  • Wall jumps and double jumps
  • Items or crates falling

Tweaking tip

Pair it with the Jump preset: jump on the way up, land on the way down. Open any variant with Edit to change it with sliders.

License

Free for commercial and non-commercial use. No attribution, no sign-up. Most sounds are synthesized from scratch; the few that use recordings use CC0 (public domain) recordings, so there are no third-party rights attached.

Generate them from code or an AI agent

The same sounds are available from the command line:

npx sfxbrew land --count 5 --out assets/sfx/landing.wav

Or let Claude Code, Cursor or any MCP client add them to your project, then ask for "land sounds":

claude mcp add sfxbrew -- npx -y sfxbrew mcp

Free agent skill that teaches your agent when and how to use it: Agensi · GitHub
