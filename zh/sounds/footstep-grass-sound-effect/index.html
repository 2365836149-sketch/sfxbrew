关于脚步（草地）音效：适用场景、技巧和授权

踩在草地和枯叶上的单个脚步，切自一段在树林里跑步的真实录音。每个变体就是一步，带一点"沙沙"的脆响，方便和走路、跑步动画对齐。 在编辑器里每按一次"重新生成"都会得到一个不同的脚步（草地）；这里的 12 个是固定的，方便分享链接。

适用场景

  • 在田野、树林、园子里行走或奔跑
  • 在草丛里潜行
  • 野外的动物和 NPC 走动
  • 户外过场动画的拟音

调音小技巧

每一步随机挑一个播放。走路时音量调小一点，跑步时保持原样。点任意一个变体的"编辑"，就能用滑杆细调。

授权

可免费用于商业和非商业用途，不需要署名，不需要注册。大部分声音是从零合成的；少数用到录音的，用的都是 CC0（公有领域）录音，不涉及任何第三方版权。

用代码或 AI agent 生成

同样的音效也可以用命令行生成：

npx sfxbrew footstepGrass --count 5 --out assets/sfx/footstep-grass.wav

或者让 Claude Code、Cursor 等支持 MCP 的工具直接加进你的项目，然后跟它说"加几个脚步（草地）音效"：

claude mcp add sfxbrew -- npx -y sfxbrew mcp
